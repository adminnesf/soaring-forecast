# Springfield Soaring Forecast v0.2 (experimental)
Adapted from tacoleman69/Newengland-flying-forecast, commit 4d56634f81e7a8ebdd0dc765bb55cbbcf929c74f, with reuse permission reported by the project requester. No upstream license file was present.

Run `pip install -r requirements.txt`, `pip install pytest`, `python -m pytest -q`, then `python -m flyforecast.springfield`. Serve the generated page with `python -m http.server 8000 --directory site`. Live API access is required. Six original model IDs retained; four additional candidate IDs are unverified and may be rejected. Ensemble providers require separate integration. Missing models are displayed. No operational flight recommendations. Hourly parcel excess of 0.5 C and sensible heating fraction of 0.3 are uncalibrated; W* is not glider climb. LCL is not observed cloud base. Airport values carried over from project plan, not independently reverified in this release. Consensus, interactive soundings, ridge/wave, actual-flight validation and alerts remain pending. Original modules retained for reference, not used for publication. Do not run original main entry point for Springfield.

Deployment: create separate GitHub repository, upload contents, enable Pages using GitHub Actions, run Forecast manually, inspect results. After validation configure custom domain weather.nesfsoaring.com and Cloudflare DNS CNAME to the actual GitHub Pages host; enable HTTPS. No DNS or production changes made. Check Open-Meteo usage terms and quotas before public deployment.
